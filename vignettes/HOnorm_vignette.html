Some tests have a hierarchical structure, such that the full test measures a certain latent trait, while subtests of the tests measure unique latent traits. Then it can be assumed that items hold information regarding a unique latent trait and a general latent trait. When applying IRT-based continous norming this hierarchical structure can be modeled with a hierachical IRT model. The norming is performed similar to unidimensional IRT-based norming but the hierachical structure has to be acknoleged in model checking. This vingette focuses on the special considerations for hierarchical test. For a general example about IRT-based norming using IRTnorm we refere to the vingette for unidimensional models.

The exemplary data we are using is generated under the HOnorm-F model with three domains. The following code loads the required package and the example data.

library(IRTnorm)
library(ggplot2)
data("HOdata")

For this example we assume we know which model fits the data best. How to select the best model is described in the 2PLnorm vingette.
